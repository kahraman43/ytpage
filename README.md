# SimpleCalc - Android Hesap Makinesi

Modern ve sade bir Android hesap makinesi uygulaması.

## Özellikler
- ✅ Toplama, çıkarma, çarpma, bölme işlemleri
- ✅ Modern ve sade arayüz
- ✅ Işık teması
- ✅ ConstraintLayout kullanımı
- ✅ Kotlin ile geliştirildi

## Android Studio'da Açma

1. Android Studio'yu açın
2. "Open an Existing Project" seçeneğini tıklayın
3. Bu klasörü seçin
4. Gradle sync işleminin tamamlanmasını bekleyin

## Geliştirme Adımları

### ✅ Adım 1: Proje Yapısı Oluşturuldu
- Klasör yapısı oluşturuldu
- Gradle yapılandırması tamamlandı
- Temel dosyalar eklendi
- Launcher icon hazırlandı

### ⏳ Adım 2: UI Tasarımı (Bekleniyor)
- activity_main.xml düzenlenecek

### ⏳ Adım 3: Hesaplama Mantığı (Bekleniyor)
- MainActivity.kt tamamlanacak

### ⏳ Adım 4-8: Diğer Adımlar
- Manifest yapılandırması
- Build ayarları
- Test
- İmzalama
- Play Store yükleme
